# GreyLab

GreyLab’s website, built with the Next.js App Router, Bun, React, TypeScript, and local media.

## Run locally

```sh
bun install
bun run dev
```

Open http://localhost:3000. For the production export:

```sh
bun run build
bun run verify
bun run start
```

The Bun production preview serves `out/` at http://127.0.0.1:4173. `PORT` and `HOST` can override its address. Set `NEXT_PUBLIC_SITE_URL` to your site’s URL before building to generate production social image URLs. The exported `out/` folder can also be deployed to a static host that maps clean paths to `.html` files.

## Where to make changes

| Folder                 | Responsibility                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `app/`                 | Route composition, metadata, and global styles                                                           |
| `components/layout/`   | Shared header, mobile navigation, footer, and closing CTA                                                |
| `components/home/`     | Individual home page sections                                                                            |
| `components/projects/` | Project cards, editorial grids, and case study template                                                  |
| `components/blog/`     | Article cards and article template                                                                       |
| `components/contact/`  | Local project brief form                                                                                 |
| `components/motion/`   | Original gradient shader, scroll easing, word reveals, sliced image reveals, and reduced motion handling |
| `components/ui/`       | Shared buttons, rolling link text, icons, and section labels                                             |
| `data/projects.ts`     | Project records, screenshots, technical highlights, and case studies                                     |
| `data/blogs.ts`        | Article records and rich text                                                                            |
| `data/team.ts`         | Verified team names, roles, portraits, and profile links                                                 |
| `lib/media.ts`         | Responsive local image lookup and display sizes                                                          |
| `styles/`              | Shared layout and scoped home/secondary page styles                                                      |
| `public/images/`       | Local images, including the GreyLab logos in `brand/`                                                    |
| `public/fonts/`        | Locally hosted fonts                                                                                     |
| `public/videos/`       | Reserved for local video assets                                                                          |

Edit project and article records to update content. After replacing project or article images, run `bun run images:optimize` to regenerate the local responsive copies. Original files are retained. Their routes are generated by `generateStaticParams` during the production build. The About link points to the homepage section at `/#about`.

## Routes

- `/`
- `/projects` and `/projects/[slug]` for published case studies
- `/blogs` and `/blogs/[slug]` for published articles
- `/contact`
- `/legal/privacy-policy`

## Motion and responsive behavior

The liquid background is rendered live by a WebGL2 fragment shader. Tune the six colors, speed, seed, turbulence, contrast, and grain in `components/motion/liquid-gradient-config.ts`; its GLSL is in `liquid-gradient-shader.ts`. GPU setup and drawing are isolated in `lib/webgl/liquid-gradient-renderer.ts`, while the React component owns visibility, resize, and animation lifecycle.

The animation uses elapsed visible seconds, so long frames do not slow its timing. GPU resources are created when the section becomes visible, rebuilt after graphics context restoration, and released on unmount. Hidden sections pause. Reduced motion uses one representative shader frame; a CSS fallback remains available when WebGL2 is unavailable.

The layout switches from desktop at 1300px to tablet at 810px, then to phone below 810px. Motion includes the title entrance, scroll text highlighting, service changes, and sticky process cards. The service labels and logo row are static. The project slideshow appears when featured project records are available.

The contact form prepares a local project brief, supports copying, and opens a draft in the visitor’s email app. Contact information and social links are defined in `data/site.ts`.

## Checks

```sh
bun run typecheck
bun run test
bun run lint
bun run format:check
bun run build
bun run verify
```

`verify` checks declared routes, exported internal links, and local assets without requiring a browser.
